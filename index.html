Apply this theme on your iPhone

iPhones don't let websites change icons, so you apply the theme yourself. Start with the quick theme; add custom icons if you want the full look.

  1. Save the wallpaper. Tap Download wallpaper and choose Save Image, so it's in Photos.
  2. Set it. Open Settings → Wallpaper → Add New Wallpaper → Photos. Pick the image, tap Add, then Set as Wallpaper Pair.
  3. Color the clock. Touch and hold the Lock Screen, tap Customize → Lock Screen, tap the time and set its color to . Tap the color wheel and use the Sliders tab to type the code.
  4. Tint the app icons (iOS 18 or later). Touch and hold an empty spot on the Home Screen, tap Edit → Customize and choose Tinted. Pick from the wallpaper with the color picker, or match it with the sliders.
  1. Get the icons. Tap Theme pack and save the .zip to Files. In Files, tap it to unzip a folder with the wallpaper and 24 icons.
  2. Put the icons in Photos (optional, easier to pick). In the icons folder tap ⋯ → Select, select them all, then Share → Save Images.
  3. Make a shortcut. Open Shortcuts, tap +, tap Add Action, search for Open App and add it. Tap App and choose the app, for example Messages.
  4. Add it to the Home Screen. Tap the menu next to the shortcut's name at the top and choose Add to Home Screen.
  5. Give it the icon. Tap the small icon, choose Choose Photo or Choose File, pick the matching icon, type the app's name and tap Add.
  6. Repeat, then tidy up. Do the same for each app you want themed. To hide an original icon, touch and hold it → Remove App → Remove from Home Screen. The app stays in the App Library.
